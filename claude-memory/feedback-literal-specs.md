Take the owner's specs literally and don't add my own reinterpretation. 2026-10-19: "first crate guaranteed uncommon" → I built "Uncommon or better" and the owner got a Rare ("no all wrong"). "Text too big, make it smaller and maybe put it somewhere else, or don't if it looks bad" → I moved it beside the button; owner said it lost its eye-catching punch.

**Why:** the owner can't read code; any drift from their words shows up as a failed test and a wasted round.
**How to apply:** "guaranteed X" = exactly X. For UI tweaks keep the existing impact (centre placement, pop) and change only what was asked; if tempted to move something, ask first. Related: [[addendum-2]].
